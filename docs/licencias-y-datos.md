# Licencias, procedencia y uso de datos

Revisión: **29 de octubre de 2026**. Este inventario distingue condiciones conocidas de decisiones pendientes; no concede derechos sobre material propio o de terceros.

| Componente                 | Evidencia local                                                                                                                         | Condición y acción                                                                                                                 |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| Código propio              | No hay `LICENSE` general; `package.json` marca el paquete como privado.                                                                 | El titular debe elegir las condiciones de distribución. No añadir una licencia por suposición ni presentar el código como abierto. |
| Dependencias               | `package.json`, lockfile y configuración Gradle.                                                                                        | Revisar licencias/avisos de las versiones distribuidas. Este documento no es un SBOM ni una revisión completa de transitivas.      |
| Inter/Montserrat           | [Inter](../src/assets/fonts/inter-LICENSE.txt), [Montserrat](../src/assets/fonts/montserrat-LICENSE.txt), copias en `public/licenses/`. | SIL OFL; conservar avisos.                                                                                                         |
| Base geográfica            | [Procedencia de Monterrey](../src/data/monterrey-map.md).                                                                               | OpenStreetMap/ODbL y atribución; revisar obligaciones para bases derivadas/distribución.                                           |
| Foto histórica de Talleres | [Autor, licencia y fuente](../public/licenses/station-photos.json).                                                                     | Conservar fecha/atribución; no representa el estado actual.                                                                        |
| Catálogos, mapas y KML     | [Metro](datos-y-fuentes.md), [autobuses](catalogo-autobuses.md), auditorías y `sources` de artefactos.                                  | La licencia de un CSV no cubre automáticamente un mapa enlazado. Registrar condiciones por fuente.                                 |
| Reportes y fotografías     | [Privacidad](../public/privacidad.html), [moderación](quejas-comunitarias.md).                                                          | Consentir publicación no concede permiso general para reutilizar fotos, entrenar modelos o compartir evidencia privada.            |

Antes de redistribuir: aprobar licencia del código, revisar avisos y condiciones de fuentes, mantener atribución y excluir material privado. Para visión computacional se necesitan condiciones específicas de captura, entrenamiento, pesos y tratamiento de terceros presentes en imágenes. No se presupone ningún convenio con operadores o autoridades.
